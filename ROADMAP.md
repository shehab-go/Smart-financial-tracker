# Smart Financial Tracker Roadmap | خارطة طريق المشروع

This document outlines the planned future for the Smart Financial Tracker library.
يوضح هذا المستند الخطة المستقبلية لتطوير مكتبة متتبع البيانات المالية الذكي.

---

## 🚀 Near Term (v1.2.x) - "The Yemeni Ecosystem" | المدى القريب: النظام المالي اليمني
- [x] **Jeeb (جيب) Integration**: Fully supported and tested. | **دعم محفظة جيب**: مدعومة ومختبرة بالكامل.
- [ ] **Yemeni Wallet Bundle**: Complete high-accuracy presets for mFloos, ONE Cash, and Mobile Money. | **حزمة المحافظ اليمنية**: استكمال الإعدادات الجاهزة لمحافظ الكريمي، ون كاش، وموبايل موني بدقة عالية.
- [ ] **CSV/Excel Export**: Allow users to export their transaction history to local files. | **تصدير البيانات (CSV/Excel)**: السماح للمستخدمين بتصدير سجل العمليات إلى ملفات محلية.
- [ ] **Yemeni Data Export**: Specific templates for local accounting and tax reporting needs in Yemen. | **تنسيق بيانات يمني**: قوالب خاصة تتناسب مع احتياجات المحاسبة والتقارير الضريبية المحلية في اليمن.
- [ ] **Charts & Statistics**: Add a basic statistics engine to the library to calculate monthly spending/income. | **الرسوم البيانية والإحصائيات**: إضافة محرك إحصائي لحساب المصروفات والدخل الشهري.

---

## 🛠️ Mid Term (v1.5.x) - "Smarter Insights" | المدى المتوسط: رؤى أكثر ذكاءً
- [ ] **AI-Powered Classification**: Integrate a lightweight on-device ML model to automatically categorize transactions (e.g., Food, Transport, Utilities). | **التصنيف بالذكاء الاصطناعي**: دمج نموذج تعلم آلي خفيف يعمل على الجهاز لتصنيف العمليات تلقائياً (طعام، نقل، فواتير).
- [ ] **Budgeting Engine**: Allow users to set monthly limits and receive notifications via the library when nearing those limits. | **نظام الميزانية**: السماح للمستخدمين بوضع حدود شهرية واستلام تنبيهات عند الاقتراب من هذه الحدود.
- [ ] **SMS History Parsing**: A tool to parse existing SMS history for historical data import. | **تحليل سجل الرسائل القديمة**: أداة لتحليل الرسائل النصية السابقة لاستيراد البيانات التاريخية.

---

## 🌟 Long Term (v2.0.0) - "Full Ecosystem" | المدى البعيد: نظام متكامل
- [ ] **Cloud Sync (Optional)**: Secure, end-to-end encrypted backup to Google Drive or iCloud. | **المزامنة السحابية (اختياري)**: نسخ احتياطي مشفر بالكامل (End-to-End) على Google Drive أو iCloud.
- [ ] **Cross-Platform Bridge (iOS)**: Bring the parsing logic to iOS via Swift (where notification listening allows). | **دعم الأنظمة الأخرى (iOS)**: نقل منطق التحليل لنظام iOS عبر لغة Swift (حيثما تسمح صلاحيات النظام).
- [ ] **Widget Support**: Ready-to-use Android widgets for real-time balance tracking. | **دعم الودجت (Widgets)**: ويدجت جاهزة للاستخدام لتتبع الرصيد في الوقت الحقيقي من الشاشة الرئيسية.
- [ ] **Expansion to React Native**: Official bridge for React Native developers. | **دعم رياكت نيتف**: توفير جسر برمجي رسمي لمطوري رياكت نيتف.
- [ ] **KMP Transition**: Migrating the core logic to Kotlin Multiplatform for shared business logic. | **التحول إلى KMP**: نقل المنطق البرمجي الأساسي لتقنية كوتلن للمنصات المتعددة لمشاركة الكود.

---

نحن نرحب باقتراحاتكم! إذا كنت ترغب في رؤية ميزة غير مدرجة هنا، يرجى فتح **طلب ميزة (Feature Request)** في تبويب المشاكل (Issues).
