# Smart Financial Tracker Roadmap

This document outlines the planned future for the Smart Financial Tracker library. We aim to make financial tracking as seamless and secure as possible.

## 🚀 Near Term (v1.2.x) - "Accessibility & Integration"
- [ ] **Multi-Bank Presets**: Add built-in regex configurations for major banks in Saudi Arabia and the Gulf region.
- [ ] **CSV/Excel Export**: Allow users to export their transaction history to local files.
- [ ] **Charts & Statistics**: Add a basic statistics engine to the library to calculate monthly spending/income.

## 🛠️ Mid Term (v1.5.x) - "Smarter Insights"
- [ ] **AI-Powered Classification**: Integrate a lightweight on-device ML model to automatically categorize transactions (e.g., Food, Transport, Utilities).
- [ ] **Budgeting Engine**: Allow users to set monthly limits and receive notifications via the library when nearing those limits.
- [ ] **SMS History Parsing**: A tool to parse existing SMS history for historical data import.

## 🌟 Long Term (v2.0.0) - "Full Ecosystem"
- [ ] **Cloud Sync (Optional)**: Secure, end-to-end encrypted backup to Google Drive or iCloud.
- [ ] **Cross-Platform Bridge (iOS)**: Bring the parsing logic to iOS via Swift (where notification listening allows).
- [ ] **Widget Support**: Ready-to-use Android widgets for real-time balance tracking.
